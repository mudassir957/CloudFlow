# CloudFlow

CloudFlow is a cloud-native distributed order processing system.

## Architecture

Microservices architecture:

- API Gateway
- User Service
- Order Service
- Notification Service

## Technologies

Backend:
- Node.js
- NestJS

Database:
- PostgreSQL

Messaging:
- RabbitMQ

Caching:
- Redis

Infrastructure:
- Docker
- Kubernetes
- Terraform
- Azure

Monitoring:
- Prometheus
- Grafana
